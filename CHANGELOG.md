## [1.0.1] - 2025-06-17

### Added
- Initial public release
- Interactive twelve-part puzzle game exploring Jewish history in Basel (1850-1914)
- Gamified learning experience with questions and content unlocking
- Museum reward system for completed puzzles
- Docker support for containerized deployment
- GitHub Pages deployment configuration
- Citation metadata (CITATION.cff)
- DOI and Software Heritage archiving

### Technical Stack
- Stencil.js web components
- TypeScript
- Ionic components
- Service worker support
- Prerendering for optimal performance

### Documentation
- Comprehensive README.md
- MIT License for code
- CC BY 4.0 License for content
- Citation guidelines
